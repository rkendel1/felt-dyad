# FeltDB Kanban Dashboard

A drag-and-drop project board with state persisted by a local Node-hosted
FeltDB server. Run `npm install`, then `npm run dev`.

This template is adapted from Briet Sparks' MIT-licensed
[Kanban Dashboard](https://github.com/brietsparks/kanban-dashboard). The
application has been modernized for Vite and its original browser
`localStorage` service has been replaced with server-backed FeltDB
collections.
